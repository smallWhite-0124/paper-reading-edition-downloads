# 论文精读版桌面端 · Downloads

本仓库仅用于发布桌面端安装包，不包含源码。

## 下载

前往 [Releases](https://github.com/smallWhite-0124/paper-reading-edition-downloads/releases) 下载最新 Windows x64 便携版。

## 使用

1. 解压 zip
2. 运行 `论文精读版.exe`
3. 打开软件设置，填写自己的 DeepSeek API Key
4. 打开本地 PDF，生成精读版
5. 导出 PDF

## 特点

- 本地优先
- 不需要登录或云端账号
- 论文和生成结果保存在本机
- API Key 使用系统安全存储加密

## 注意

- 当前为 v0.1.0 原型，复杂公式、双栏和表格解析仍需完善
- 当前未进行代码签名，Windows 可能显示未知发布者/SmartScreen 提示
- 首次运行可能需要允许 Windows 防火墙网络访问，软件需要调用模型 API
